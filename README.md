# ProiectTW2026

Proiect pentru etapa 1 la Tehnici Web. Site-ul este o pagina HTML statica cu tema "Apex Auto Shop".

## Structura

- `index.html` - pagina principala.
- `resurse/ico/` - favicon, iconite pentru dispozitive si `site.webmanifest`.
- `resurse/imagini/` - imaginile SVG folosite in pagina.
- `resurse/descarcari/` - fisierul text oferit la download din pagina.
- PDF-ul din radacina proiectului - catalogul afisat in pagina prin elementul `<object>`.
- `scripts/etapa1-check.js` - verificare rapida pentru elementele de baza cerute in etapa.
- `dist/` - materiale de lucru si fisiere PDF folosite ca referinta; nu sunt necesare pentru rularea paginii.
- `package.json` - scripturile Node pentru verificare locala.
- `index.js` - fisier placeholder; nu este folosit de pagina.
- Proiectul foloseste doar HTML static si resurse locale.
- Nu exista dependente de instalat pentru a deschide pagina.
